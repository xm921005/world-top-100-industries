# 全球最赚钱 100 个行业

> 每 30 分钟自动更新的行业赚钱效应榜单。

## 这是什么

用一组覆盖各细分行业的**美股行业 / 主题 ETF** 作为「行业代理」，抓取其公开行情，计算区间收益率并排名，取近 1 个月表现最好的 100 个行业。数据源为 Yahoo Finance 公开接口，无需密钥。

## 口径说明（重要）

- **行业如何表示**：没有一个权威接口能直接给出「全球最赚钱的 100 个行业」实时排名，因此采用约 110 个覆盖各细分领域的美股行业 / 主题 ETF 作为代理（科技、半导体、云计算、金融、医疗、能源、消费、军工、黄金、铜、清洁技术等）。
- **收益率的单位**：全部为**百分比（%）**，不是固定金额、不是概率。
  - `近1月收益率(%)`：约 30 天前收盘价 → 最新收盘价的价格变动百分比，未计股息、未年化。
  - `近3月收益率(%)`：约 90 天区间变动百分比。
  - `近1年收益率(%)`：约 365 天区间变动百分比。
- **排名依据**：按 `近1月收益率(%)` 从高到低排序。数值越高代表最近一段时间该行业代理 ETF 涨得越多。
- **局限**：这是「最近涨得最多的行业」的可量化代理，不等同于会计意义上的行业净利润；美股 ETF 也不完全代表全球所有行业。

## 数据文件

- `README.md`：本页，含最新榜单（自动生成区块）。
- `data/latest.json`：机器可读的最新完整数据（含更新时间、口径、Top100 明细）。
